# 香港大战僵尸 (HK vs Zombies)

一款受 Ninja Kiwi《Zombie Trailer Park》（国内 4399 叫"建筑队大战僵尸"）启发的横版拔河 RTS 网页小游戏。

- 单条中路对战、经济+人口+能量三资源、Yee-Haw 大招
- **6 个"文明"**（3 香港：金融中心 / 贫民窟 / 差馆；3 僵尸：末日尸潮 / 港式怪谈 / 病毒实验体）
- **1v1 / 2v2 支持**（人机混合）
- 联机使用 GameHub 房间转发；接入统计、成就、排行榜、对局历史

## 开发

```
src/         # 游戏源码，会被打包上传
build.ps1    # 打包 zip
deploy.ps1   # 推到 GameHub
```

参见 `GDD_ZombieTrailerPark_Reforged.md` 的核心玩法策划案。
